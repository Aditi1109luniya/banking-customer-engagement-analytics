# Interview presentation

Five slides cover the business problem, data pipeline, leakage and evaluation, measured results, and relationship-manager workflow.

- `interview_deck.pptx` contains editable native text, tables, and a cumulative gain chart, plus source-cited speaker notes.
- `interview_deck.pdf` is a sharp raster preview for reading and sharing. It does not provide searchable text. Native PDF export was unavailable in the authoring runtime.
- `speaker_notes.md` provides the full speaking script and source references.

The chart displays measured recall rounded to eight decimal places for portable chart workbook storage. Full precision remains in the model artifacts. The deck was rendered and visually reviewed through the authoring runtime. It was not opened in Microsoft PowerPoint.
